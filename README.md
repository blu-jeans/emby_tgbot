# 🤖 Emby Telegram 自助开号机器人

这是一个专为 Emby 影视服务器服主设计的 **Telegram 自动自助开号系统**。通过该系统，您的群友可以通过与 Telegram 机器人私聊，自助创建并绑定自己的 Emby 账号，极大地减少了服主人工开号的繁琐工作。

系统配备了精美的深色磨砂玻璃（Glassmorphism）极客风配置后台，让您可以通过网页直接配置所有参数。

---

## ✨ 亮点特性

* 📦 **极速部署**：完全基于 Docker，内置 SQLite 数据库。无需繁琐的数据库配置和手动建表，一键拉起即可使用。
* ⚙️ **网页可视化配置**：所有的 Bot Token、群组白名单、Emby 地址和 API 密钥都可在网页端配置。保存后机器人**自动热重载生效**，无需重启容器或 Python 进程。
* 🏷️ **多群组白名单**：支持配置多个 Telegram 授权群组。前端提供非常现代的“胶囊标签”输入机制，自动拦截非数字输入。
* 🔒 **防滥用设计**：限制用户仅能在私聊中开号防泄露密码；自动验证用户是否在白名单群组内（退群则失去访问资格）；每个 Telegram 账户终身限开一个账号。
* 📋 **默认 Policy 预填**：直接在配置后台中为您呈现 Emby 开号默认策略包的完整 JSON，您可以直接在网页中微调权限（如关闭转码、关闭下载、隐藏用户等）并即时应用。

## 🚀 部署指南 (Docker Compose)

您无需下载整个项目源码，只需在一个空文件夹内创建一个 `docker-compose.yml` 文件，填入以下配置即可拉起服务：

### 1. 编写配置文件 `docker-compose.yml`

```yaml
version: '3.8'

services:
  emby-tgbot:
    image: fckipk/emby-tgbot:latest
    container_name: emby_tgbot_app
    restart: unless-stopped
    ports:
      - "5000:5000"
    volumes:
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
      - WEB_PORT=5000
```

### 2. 运行启动命令

在包含 `docker-compose.yml` 的目录下，运行以下指令：

```bash
docker compose up -d
```

启动完成后，系统将自动在同级目录下生成 `data/` 目录来存放所有配置和用户注册数据。即使升级镜像或重启容器，数据也不会丢失。

## ⚙️ 管理后台配置步骤

服务启动后，在浏览器访问：`http://你的服务器IP:5000` 进入管理后台。

### 1. 登录并修改安全密码
* **默认管理员用户名**：`admin`
* **默认管理员密码**：`admin`
* ⚠️ **安全警告**：首次登录后，请滚动到页面最下方，**立即修改管理员原密码**以确保您的系统安全。

### 2. 填写系统参数
在页面左侧的【系统参数配置】中依次填入：
* **Telegram Bot Token**：从 TG 官方机器人 `@BotFather` 处申请的 Bot Token。
* **白名单群组 ID**：填入您允许开号的群组 ID（必须以 `-100` 开头的数字），**按回车键**即可生成胶囊标签。支持添加多个群组。
* **Emby 内网地址**：容器或主机访问 Emby 服务器的地址（例 `http://172.17.0.1:8096`）。
* **Emby API Key**：在 Emby 后台 -> 仪表盘 -> 高级 -> 【API 密钥】 中生成并复制过来。
* **Emby 外部反代地址**：开号成功后发给用户的 Emby 连接地址（如配置了公网反代、CDN 的地址，例 `https://emby.domain.com`）。
* **默认参考用户 ID**：在 Emby 网页端进入任意一个已有用户的配置详情页，复制 URL 中 `userId=` 后面的那一串哈希字符。新用户的属性将克隆自该用户。
* **自定义策略 JSON**：系统已预填了默认的高安全性开号策略（限制转码、关闭下载、隐藏用户等）。您可以直接修改对应布尔值，也可以保持默认。

填写完毕后，点击 **保存设置并重载 Bot**，机器人将在后台自动连线，开启工作。

## 💬 机器人使用与注册指令

把您的机器人分享给群友。群友使用时需要遵守以下步骤：

1. **私聊**您的机器人，发送 `/start`。
2. **开号指令**：发送 `/createaccount <您想要的用户名>`（例：`/createaccount user123`）。
3. **开号规则限制**：
   * 用户名必须由纯英文和数字组成。
   * 用户**必须在您指定的白名单群组中**。
   * 每个 Telegram 账号**只允许注册并绑定一个** Emby 账号。
   * 创建成功后，机器人会私聊发送生成的随机强密码、用户名以及您的 Emby 访问地址给用户。
